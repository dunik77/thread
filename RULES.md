# Rules

These are the ground rules for anything this project ever outputs, in code or in a tweet. They exist because the subject matter is real addresses, real money, and real reputational damage if it's wrong. They come before the spec, not after it.

## 1. Evidence, never a verdict

thread states what a transaction shows. It never states what that means about a person.

Allowed: "Address A received 4.2 ETH from address B at block 1,204,551, three minutes before A bought into this launch."

Not allowed: "A and B are the same wallet." "This is an insider ring." "This deployer is a scammer."

The reader draws the conclusion. thread hands them the transaction hash to check it themselves.

## 2. No score, no rank

A single number invites trust it hasn't earned. Every output is a list of specific, dated, sourced facts — never collapsed into a 0–100 score, a percentage, or a "risk level" label.

## 3. Missing data stays missing

If a fee-escrow recipient can't be resolved, or a deployer's earlier history is outside the indexed range, the case file says so explicitly. It is never rounded down to "clean."

## 4. Same funding source is not same owner

A shared upstream address — including a shared exchange withdrawal address — is disclosed as a fact with a timestamp. It is never presented as proof of common control. This is the single easiest way for this project to accidentally defame someone, and it's the rule most likely to be tempting to bend for a punchier tweet. It does not get bent.

## 5. No custody, no execution

thread never holds a private key, never signs a transaction, and never places a trade on anyone's behalf. It reads. It does not act.

## 6. Every claim links to its receipt

A transaction hash, a block number, or an event log entry accompanies every fact in a case file. A claim with no receipt does not ship.

## 7. Shareable does not mean simplified past the point of accuracy

A case file built for Twitter carries the same evidence and the same hedges as the full page. Compressing "received funds from" into "controlled by" to fit a tweet is not a shortcut — it's a different, false claim.
